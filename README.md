u## Which config should I use?

There are two versions. Both block ads, trackers and adult websites.
The only difference:

- **Standard** – pornhub.com is NOT blocked:
  [sing-box-v18.json](https://raw.githubusercontent.com/alienthrone/sing-box-rules/main/config/sing-box-v18.json)

- **Strict** – pornhub.com is blocked too (recommended for children's devices):
  [sing-box-v18-strict.json](https://raw.githubusercontent.com/alienthrone/sing-box-rules/main/config/sing-box-v18-strict.json)

## How to set it up

1. Right-click the link of the version you want → **Copy Link**.
2. In the sing-box app: **Profiles → New Profile**
   - **Type:** Remote
   - **URL:** paste the link
   - **Auto Update:** on
3. Save, select the profile, and start sing-box.

The profile updates itself automatically. Please don't edit its content
in the app – changes are overwritten at the next update.
To switch versions, create a new profile with the other link.
